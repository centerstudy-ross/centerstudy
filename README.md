# centerstudy website

Plain HTML — no build step.

## Publish with GitHub Pages
1. Upload everything in this folder to the root of the `centerstudy-ross/centerstudy` repository (Add file → Upload files → drag all files/folders → Commit).
2. In the repo: Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
3. After a minute the site is live at https://centerstudy-ross.github.io/centerstudy/

## Custom domain (optional)
Settings → Pages → Custom domain → enter your domain, then add the DNS records GitHub shows you at your domain registrar.

## Editing
Each page is its own file: index.html, what.html, about.html, offerings.html, objects.html. Edit text directly in GitHub (pencil icon) and commit.
